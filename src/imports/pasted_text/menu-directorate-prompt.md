# FIGMA MAKE MASTER PROMPT

## ICT-ASSISTED FOOD MENU DIRECTORATE SYSTEM

### Case Study: Ikot Ekpene, Akwa Ibom, Nigeria

Design and build a complete, professional, responsive web application called:

**ICT-Assisted Food Menu Directorate System**

Case Study:

**Ikot Ekpene, Akwa Ibom, Nigeria**

The application is a digital food/menu management and meal-planning system designed to replace the traditional manual process where a cook thinks about what to prepare, manually determines the ingredients, searches for cooking instructions, and writes meal timetables in notebooks.

The proposed system should centralize meals, ingredients, preparation instructions, cooking procedures and meal timetables in a structured digital system.

The system must allow users to:

1. Browse available meals
2. Search for meals
3. View meal information
4. View required ingredients
5. View ingredient quantities
6. Follow step-by-step cooking instructions
7. Add meals to a personal timetable
8. View daily and weekly meal plans
9. Organize meals by breakfast, lunch and dinner
10. Save favorite meals
11. Manage their profile

The system must also include an administrator interface for managing:

* Meals
* Meal categories
* Ingredients
* Recipes
* Cooking instructions
* Meal timetables
* Users
* Content

Build this as a complete academic software project that can be demonstrated during a project defense.

Do not design only a landing page.

Design the complete system from start to finish.

---

# 1. CORE PRODUCT CONCEPT

The central user journey is:

**Choose a meal → View ingredients → View preparation → Follow cooking steps → Add meal to timetable**

The application should make cooking and meal planning easier by replacing the existing manual process with a centralized digital database.

The application is NOT primarily:

* A restaurant marketplace
* A food delivery application
* An online food ordering application
* A payment platform

Do not make restaurant ordering, delivery tracking or online payment part of the core MVP.

This is primarily a:

**Meal Directory + Recipe Database + Cooking Guide + Food Timetable System**
